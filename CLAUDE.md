# Platinumlist Design System WEB

## О проекте

Это дизайн-система Platinumlist — набор React-компонентов с CSS Modules и токенами. Storybook для документации.

## Команды

- `npm run storybook` — запуск Storybook (порт 6006)
- `npm run build` — сборка
- `npm run dev` — dev-сервер Vite

## Структура

- `src/styles/tokens.css` — дизайн-токены (единственный источник правды для цветов, шрифтов, отступов)
- `src/components/` — компоненты (21 шт.)
- `.storybook/` — конфигурация Storybook

## Правило для Claude

При создании **прототипов, веб-страниц, лендингов, макетов и любого UI** — используй скилл `/design-system` для получения полной справки по токенам, компонентам и правилам дизайн-системы Platinumlist.
